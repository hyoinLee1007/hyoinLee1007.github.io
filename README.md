# Hyoin Lee — GitHub Pages Portfolio

GitHub Pages용 개인 연구 홈페이지입니다.

## 배포

GitHub 계정 `hyoinLee1007`에서 아래 이름으로 저장소를 생성합니다.

```text
hyoinLee1007.github.io
```

이 폴더의 **내용 전체**를 저장소 최상위 경로에 올린 뒤 `main` 브랜치에 push하면 됩니다.

최종 주소:

```text
https://hyoinLee1007.github.io/
```
